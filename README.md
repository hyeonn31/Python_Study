# 🐍 Python 데이터 분석 공부 기록

파이썬 기초부터 데이터 분석까지 공부하면서 실습한 코드를 모아 두는 저장소입니다.
처음 배우는 과정이라 시행착오와 메모도 함께 남겨 두고 있어요.

## 📌 목표

- 파이썬 기본 문법(리스트, 딕셔너리, 반복문, 함수)을 익히기
- 데이터를 직접 가공하고 분석하는 힘 기르기
- 꾸준히 기록하면서 성장 과정 남기기

## 📂 실습 목록

| 파일 | 주제 | 배운 점 |

| [0.test.ipynb](0.test.ipynb) | 주간 식단 칼로리 분석 | 딕셔너리 순회, 이중 반복문, 최댓값/최솟값 찾기, 리스트 컴프리헨션, 함수 나누기 |

## 🛠 사용 도구

- Python 3
- Jupyter Notebook (VS Code)

## 📝 공부하면서 기억할 것

- 모르겠으면 일단 `print()`로 변수 안을 확인해 보기
- 노트북은 위에서부터 순서대로 실행하기 (`NameError`가 나면 실행 순서부터 의심하기)
- 함수가 `return`하는 값을 보면 받는 방법이 보인다
