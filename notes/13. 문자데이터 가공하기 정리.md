# 문자데이터 가공하기 정리 (airbnb 숙소 데이터로)

12번에서 결측값, 중복값, 이상점을 정리했는데, 데이터를 보다 보면 또 거슬리는 게 있다.
`Illinois`, `ILLINOIS`, `illinois`가 따로 놀고, `location`에는 동네랑 도시가 한 칸에 같이 들어 있고, 도시 이름 끝에는 마침표가 붙어 있다.
이번엔 이런 **문자 데이터를 다듬는 법**을 배웠다. 핵심은 딱 하나, `.str`이다.

---

## 시작 전에

### 데이터

12번이랑 같은 airbnb 숙소 데이터다. 713줄.

```python
import pandas as pd

airbnb_df = pd.read_csv('data/airbnb.csv')
```

이번에 다룬 열은 두 개다.

| 열 | 들어 있는 값 | 문제 |
|---|---|---|
| `state` | `Illinois`, `ILLINOIS`, `illinois`... | 대소문자가 제각각 |
| `location` | `Avondale, Chicago.` | 동네 + 도시가 한 칸에, 끝에 마침표 |

## 1. .str이 뭐길래

처음에 이렇게 썼다가 에러가 났다.

```python
airbnb_df['state'].lower()
```

```
AttributeError: 'Series' object has no attribute 'lower'
```

`lower()`는 파이썬에서 문자열을 소문자로 바꾸는 함수인데 왜 안 될까.

1. `lower()`, `replace()`, `split()` 같은 함수는 원래 **문자열 하나**에 쓰는 함수다.
   ```python
   'SEOUL'.lower()   # 'seoul' → 잘 됨
   ```
2. 그런데 `airbnb_df['state']`는 문자열이 아니라 **시리즈**(문자열 713개가 든 상자)다. 상자 자체에는 `lower()`가 없다.
3. `.str`을 붙이면 상자를 열어서 **값 하나하나에** 함수를 적용해 준다.

```python
airbnb_df['state'].str.lower()
```

아래 반복문을 한 줄로 쓴 거라고 생각하면 된다.

```python
[s.lower() for s in airbnb_df['state']]
```

`.str`은 결측값(NaN)이 섞여 있어도 에러 없이 NaN으로 남겨 둔다. 반복문으로 직접 하면 NaN에서 에러가 난다.

**규칙: 시리즈에 문자열 함수를 쓰려면 앞에 `.str`을 붙인다.**

이 노트북은 위 에러 셀(셀 2) 때문에 **Run All을 누르면 거기서 멈춘다.** 지우거나, 셀 3부터 따로 실행해야 한다.

## 2. 대소문자 통일하기

```python
airbnb_df['state'].unique()
```

```
['Illinois', 'MASSACHUSETTS', 'ILLINOIS', 'california', 'massachusetts',
 'California', 'Massachusetts', 'CALIFORNIA', 'illinois']
```

실제로는 주가 3개(일리노이, 매사추세츠, 캘리포니아)인데, 대소문자가 달라서 pandas는 **9개의 다른 값**으로 본다.
이대로 `value_counts()`를 하면 `California` 165, `california` 90, `CALIFORNIA` 79처럼 쪼개져서 나온다. 같은 주끼리 묶어서 세려면 통일해야 한다.

| 함수 | 결과 | 예 |
|---|---|---|
| `.str.lower()` | 전부 소문자 | `illinois` |
| `.str.upper()` | 전부 대문자 | `ILLINOIS` |
| `.str.capitalize()` | 첫 글자만 대문자, 나머지 소문자 | `Illinois` |

주 이름은 원래 첫 글자만 대문자니까 `capitalize()`로 했다.

```python
airbnb_df['state'] = airbnb_df['state'].str.capitalize()
```

```
California       334
Massachusetts    204
Illinois         175
```

9개가 3개로 정리됐다. (165 + 90 + 79 = 334)

`capitalize()`는 **문자열 전체에서 첫 글자 하나만** 대문자로 만든다. `'new york'`은 `'New york'`이 된다. 단어마다 첫 글자를 대문자로 하고 싶으면 `.str.title()`을 쓰면 `'New York'`이 된다.

스마트폰 실습의 `brand` 열도 `apple`, `APPLE`, `samsung`, `SAMSUNG`처럼 섞여 있어서 똑같이 `capitalize()`로 정리했다.

## 3. 문자열 나누기: split()

`location`에는 `'Avondale, Chicago.'`처럼 동네와 도시가 쉼표로 붙어 있다. 이걸 두 열로 나눴다.

### split()으로 자르기

```python
airbnb_df['location'].str.split(',')
```

```
0     [Avondale,  Chicago.]
1     [South End,  Boston.]
...
```

**쉼표를 기준으로 잘라서 리스트로** 만들어 준다. 칸마다 `['Avondale', ' Chicago.']` 같은 리스트가 들어간다.
기준 글자(쉼표)는 **잘라 내면서 버려진다.** 결과에 쉼표가 안 남는다.

### .str[0], .str[1]로 꺼내기

```python
airbnb_df['location'].str.split(',').str[0]   # 'Avondale'   (첫 번째)
airbnb_df['location'].str.split(',').str[1]   # ' Chicago.' (두 번째)
```

리스트에서 몇 번째 것을 꺼낼지 정한다. 0부터 센다.
여기서도 `.str`이 붙는다. 칸마다 리스트가 들어 있으니까, "각 리스트에서 0번째를 꺼내라"는 뜻이다. `.str` 없이 `[0]`만 쓰면 시리즈의 0번 행을 가져와 버린다.

```python
airbnb_df['neighborhood'] = airbnb_df['location'].str.split(',').str[0]
airbnb_df['city'] = airbnb_df['location'].str.split(',').str[1]
airbnb_df = airbnb_df.drop(columns='location')
```

없는 열 이름에 값을 넣으면 **새 열이 생긴다.** `neighborhood`, `city` 열을 만들고, 다 쓴 `location`은 지웠다.

### 열 지웠는데 다른 열까지 사라진 줄 알았던 것

`location`을 지웠는데 `neighborhood`, `city`까지 같이 사라졌다.

1. `neighborhood`, `city`는 CSV에 원래 있던 열이 아니라, 셀을 실행해서 **메모리에서 만든** 열이다.
2. 중간에 `read_csv` 셀을 다시 실행하면 `airbnb_df`가 원본 CSV로 새로 만들어져서, 만든 열들이 날아간다.
3. 그 상태로 `drop` 셀만 실행하니까 두 열이 없는 결과가 나온 것.

`drop`은 지정한 열 하나만 지운다. 결과가 이상하면 **셀을 실행한 순서**부터 의심하기.

## 4. 불필요한 문자 제거하기

### 왜 Boston이 안 나오지?

```python
airbnb_df[airbnb_df['city'] == 'Boston']
```

```
Empty DataFrame
```

보스턴 숙소가 분명 있는데 0개가 나왔다.

```python
airbnb_df['city'].unique()
```

```
[' Chicago.', ' Boston.', ' San Francisco.', ' Los Angeles.']
```

**앞에 공백, 뒤에 마침표**가 붙어 있었다. `'Boston'`과 `' Boston.'`은 다른 문자열이라 하나도 안 걸린 것.
원래 데이터가 `'Avondale, Chicago.'`처럼 쉼표 뒤에 띄어쓰기가 있어서, 쉼표로만 자르면 공백이 도시 쪽에 붙어 온다.
눈으로 표를 볼 땐 공백이 잘 안 보이니까, 비교가 이상하게 안 되면 `unique()`로 실제 값을 확인해 보자.

### strip(): 양 끝 공백 지우기

```python
airbnb_df['city'] = airbnb_df['city'].str.strip()
```

괄호 안을 비워 두면 **양쪽 끝의 공백**(띄어쓰기, 탭, 줄바꿈)을 지운다. `' Boston.'` → `'Boston.'`
가운데 공백은 안 건드린다. `'San Francisco'` 사이의 띄어쓰기는 그대로 남는다.

괄호 안에 글자를 넣으면 그 글자들을 양 끝에서 지운다.

```python
.str.strip()      # 양 끝 공백
.str.strip(')')   # 양 끝의 )
.str.strip('()')  # 양 끝의 ( 와 ) 둘 다
```

지울 글자들은 **문자열 하나로 묶어서** 넣는다. `strip('(', ')')`처럼 쉼표로 나눠 넣으면 에러가 난다.

```
StringMethods.strip() takes from 1 to 2 positional arguments but 3 were given
```

내가 넣은 건 2개인데 3개라고 나오는 건, 파이썬이 함수의 대상(자기 자신)까지 하나로 세기 때문이다.

### replace(): 글자 바꾸기

```python
airbnb_df['city'] = airbnb_df['city'].str.replace('.', '', regex=False)
```

`replace('찾을 것', '바꿀 것')`. 마침표를 빈 문자열 `''`로 바꿨다 = 지웠다.

```
Los Angeles      249
Boston           204
Chicago          175
San Francisco     85
```

이제 `airbnb_df[airbnb_df['city'] == 'Boston']`이 204줄 나온다.

#### regex=False는 왜 붙였나

`regex`는 **정규표현식**이라는 문자열 패턴 문법을 쓸지 정하는 옵션이다.
정규표현식에서 `.`은 "마침표"가 아니라 **"아무 글자 하나"**라는 뜻이다. 그래서 `regex=True`로 `'.'`을 지우면 마침표만이 아니라 **모든 글자가 다 지워진다.** (`'a.b'` → `''`)

`regex=False`로 하면 `.`을 그냥 마침표 글자로 본다. 지금 pandas 버전은 기본값이 `False`라 안 써도 되지만, 노트북에 쓴 것처럼 붙여 두면 헷갈릴 일이 없다.

## 5. strip()이랑 replace() 차이

제일 헷갈렸던 부분. 차이는 **어디를 건드리느냐**다.

```python
s = ' iPhone 14 Pro '

s.strip()            # 'iPhone 14 Pro'  → 양 끝만, 가운데 공백은 그대로
s.replace(' ', '')   # 'iPhone14Pro'    → 어디에 있든 전부
```

| | `strip()` | `replace()` |
|---|---|---|
| 건드리는 곳 | **양쪽 끝만** | **어디든 전부** |
| 할 수 있는 것 | 지우기만 | 지우기 + 다른 글자로 바꾸기 |
| 넣는 값 | 지울 글자들 `strip('()')` | (찾을 것, 바꿀 것) `replace('GB', '')` |

**언제 뭘 쓰나**

| 상황 | 함수 | 예 |
|---|---|---|
| 앞뒤 공백·기호만 떼기 | `strip` | `' Boston.'`의 앞 공백 |
| 끝에만 붙은 단위 떼기 | `strip` | `'6.1"'` → `'6.1'` |
| 가운데 글자도 지우기 | `replace` | `'1,200,000'` → `'1200000'` |
| 다른 글자로 바꾸기 | `replace` | `'256GB'` → `'256기가'` |

판단 기준: **지우려는 글자가 가운데에도 있을 수 있나?** 끝에만 있으면 `strip`, 가운데도 있거나 바꿔야 하면 `replace`.

도시 이름의 마침표는 끝에만 있어서 사실 `strip`으로도 된다. 공백이랑 마침표를 한 번에 지울 수도 있다.

```python
airbnb_df['city'] = airbnb_df['city'].str.strip(' .')   # 양 끝의 공백과 마침표
```

### .str을 빼먹으면?

`replace`는 특히 조심해야 한다. 시리즈에 `.str` 없는 `replace()`도 따로 있어서 **에러가 안 난다.** 대신 하는 일이 다르다.

| | 하는 일 | `'New York'`에서 `'New'` → `'Old'` |
|---|---|---|
| `.str.replace()` | 값 **안의 일부 글자**를 바꿈 | `'Old York'` |
| `.replace()` | 값 **전체가 정확히 같을 때만** 바꿈 | 그대로 `'New York'` |

`.str`을 빼먹으면 에러도 없이 아무것도 안 바뀌어서 알아채기 어렵다.

## 스마트폰 실습에서 배운 것

### 괄호로 모델명과 용량 나누기

`name`이 `'iPhone 14 Pro (256GB)'` 모양이라 `(`로 잘랐다.

```python
cellphone_df['model'] = cellphone_df['name'].str.split('(').str[0].str.strip()
cellphone_df['capacity'] = cellphone_df['name'].str.split('(').str[1].str.strip(')')
cellphone_df = cellphone_df.drop(columns='name')
```

```
'iPhone 14 Pro (256GB)'.split('(')
→ ['iPhone 14 Pro ', '256GB)']
```

- `split`은 기준 글자를 버리니까 `(`가 사라진다. 처음엔 `capacity`에 `(`가 없어서 이상하다고 생각했는데, 원래 그렇다.
- 모델명 끝에 공백이 남아서 `.str.strip()`으로 지웠다. 문제에서 "모델명 앞뒤에 불필요한 공백이 없도록"이라고 한 게 이것.
- 용량 끝에 `)`가 남아서 `.str.strip(')')`으로 지웠다.

이렇게 `.str.함수()`를 계속 이어 붙일 수 있다. 앞 함수의 결과에 다음 함수가 적용된다.

### 오타로 난 에러

```python
cellphone_df['name'].str.split('(').str[0],str.strip()
```

```
TypeError: unbound method str.strip() needs an argument
```

점(`.`)이 아니라 **쉼표(`,`)**를 찍었다. 쉼표가 들어가면 파이썬이 `(시리즈, str.strip())` 두 덩어리로 읽어서, `str.strip()`을 대상 없이 부른 게 된다.
에러 메시지가 이상하면 오타부터 보자.

### 기호 지우고 숫자로 바꾸기

`size`가 `'6.1"'`처럼 인치 기호가 붙어 있어서 문자(`str`) 타입이었다.

```python
cellphone_df['size'] = cellphone_df['size'].str.strip('"').astype(float)
```

기호를 지운 다음에 `astype(float)`로 숫자 타입까지 바꿔야 한다. `"`만 지우고 끝내면 겉보기엔 숫자인데 타입은 여전히 문자라서, 계산이나 정렬이 이상하게 된다. `cellphone_df.dtypes`로 `float64`가 됐는지 꼭 확인하기.

## 한눈에 보기

| 하고 싶은 것 | 코드 |
|---|---|
| 어떤 값들이 있나 | `df['열'].unique()` |
| 소문자 / 대문자 | `.str.lower()` / `.str.upper()` |
| 첫 글자만 대문자 | `.str.capitalize()` |
| 단어마다 첫 글자 대문자 | `.str.title()` |
| 기준 글자로 자르기 | `.str.split(',')` |
| 자른 것 중 n번째 | `.str.split(',').str[0]` |
| 양 끝 공백 지우기 | `.str.strip()` |
| 양 끝 특정 글자 지우기 | `.str.strip('()')` |
| 글자 바꾸기 / 지우기 | `.str.replace('.', '', regex=False)` |
| 문자 → 숫자 | `.astype(float)` |
| 새 열 만들기 | `df['새 열'] = ...` |
| 열 지우기 | `df.drop(columns='열')` |

### 꼭 기억할 것 세 가지

1. **시리즈에 문자열 함수를 쓸 땐 `.str`.** 빼먹으면 에러가 나거나(`lower`), 에러 없이 엉뚱하게 동작한다(`replace`).
2. **비교가 안 되면 `unique()`로 실제 값 확인.** 눈에 안 보이는 공백이나 마침표가 붙어 있는 경우가 많다.
3. **`strip`은 양 끝만, `replace`는 전부.** 지우려는 글자가 가운데에도 있는지로 고른다.
