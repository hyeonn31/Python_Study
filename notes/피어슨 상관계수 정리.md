# 피어슨 상관계수 쉽게 정리하기

## 1. 한 줄 요약

> **피어슨 상관계수 = 두 변수가 "얼마나 같이 움직이는지"를 -1 ~ 1 사이 숫자로 나타낸 값**

---

## 2. 값의 의미

| 상관계수 값 | 의미 | 예시 |
|---|---|---|
| **1에 가까움** | 강한 **양**의 상관관계 (하나가 오르면 다른 것도 오름) | 공부 시간 ↑ → 시험 점수 ↑ |
| **0에 가까움** | 거의 상관없음 | 신발 사이즈 ↔ 시험 점수 |
| **-1에 가까움** | 강한 **음**의 상관관계 (하나가 오르면 다른 것은 내림) | 기온 ↑ → 패딩 판매량 ↓ |

```
-1 ──────────── 0 ──────────── 1
강한 음의 관계   관계 없음   강한 양의 관계
```

---

## 3. 먼저 알아야 할 것: 공분산 (Covariance)

### 공분산이란?
두 변수가 **같은 방향으로 움직이는지, 반대 방향으로 움직이는지** 알려주는 값입니다.

### 계산 방법 (3단계)
1. 각 값에서 **평균을 뺀다** → "평균보다 얼마나 크거나 작은지" (편차)
2. X의 편차 × Y의 편차를 **곱한다**
3. 다 **더해서** 데이터 개수 `n`으로 **나눈다** (= 평균을 낸다)

$$
\text{cov}(X, Y) = \frac{\sum_{i=1}^{n}(X_i - \bar{X})(Y_i - \bar{Y})}{n}
$$

- $X_i, Y_i$ : 각각의 데이터 값
- $\bar{X}, \bar{Y}$ : X와 Y의 평균
- $n$ : 데이터 개수

### 왜 곱하면 방향을 알 수 있을까?
| X 편차 | Y 편차 | 곱 | 해석 |
|---|---|---|---|
| + (평균보다 큼) | + (평균보다 큼) | **+** | 같이 큼 → 같은 방향 |
| − (평균보다 작음) | − (평균보다 작음) | **+** | 같이 작음 → 같은 방향 |
| + | − | **−** | 반대 방향 |
| − | + | **−** | 반대 방향 |

👉 결과가 **양수**면 같이 움직이고, **음수**면 반대로 움직인다는 뜻!

---

## 4. 공분산의 문제점: 단위에 따라 값이 달라진다 😵

예를 들어 "키와 몸무게"의 공분산을 구한다고 해봅시다.

- 키를 **m** 단위로 쓰면 → 공분산이 작게 나옴
- 키를 **cm** 단위로 쓰면 → 공분산이 **100배** 크게 나옴

관계는 똑같은데 숫자만 커진 거예요!
그래서 공분산이 크게 나와도 **"진짜 관계가 강한 건지, 단위 때문에 숫자가 큰 건지"** 알 수가 없습니다.

---

## 5. 해결책: 피어슨 상관계수 ✨

공분산을 **각 변수의 표준편차의 곱으로 나눠서** 단위를 없애버립니다.

$$
\rho_{X,Y} = \frac{\text{cov}(X, Y)}{\sigma_X \, \sigma_Y}
$$

- $\text{cov}(X, Y)$ : X와 Y의 공분산
- $\sigma_X, \sigma_Y$ : X와 Y의 표준편차
- $\rho$ (로) : 모집단의 피어슨 상관계수

이렇게 하면
- ✅ 값이 항상 **-1 ~ 1** 사이로 맞춰짐
- ✅ 단위(cm, m, kg, 톤 …)와 **상관없이** 비교 가능

> 💡 비유: 공분산은 "각자 다른 자로 잰 길이", 상관계수는 "모두 같은 자로 다시 잰 길이"

---

## 6. 공분산 vs 상관계수 비교

| | 공분산 | 피어슨 상관계수 |
|---|---|---|
| 알려주는 것 | 관계의 **방향** | 관계의 **방향 + 강도** |
| 값의 범위 | 제한 없음 | **-1 ~ 1** |
| 단위 영향 | **받음** ❌ | **안 받음** ✅ |
| 서로 다른 데이터끼리 비교 | 어려움 | 쉬움 |

---

## 7. 파이썬으로 구해보기

```python
import pandas as pd

df = pd.DataFrame({
    'study_hours': [1, 2, 3, 4, 5],
    'score':       [50, 60, 65, 80, 90],
})

# 공분산 (pandas는 n이 아니라 n-1로 나눔 = 표본 공분산)
print(df.cov())

# 피어슨 상관계수 (기본값이 pearson)
print(df.corr())
print(df['study_hours'].corr(df['score']))
```

> 참고: 위 수식은 모집단 기준이라 `n`으로 나누지만, pandas `cov()`는 표본 기준이라 `n-1`로 나눕니다.
> 상관계수는 어느 쪽으로 계산해도 결과가 같아요.

---

## 8. 핵심 정리 ✅

1. **공분산**: 두 변수가 같은 방향/반대 방향으로 움직이는지 알려줌 → 하지만 **단위에 따라 값이 들쭉날쭉**
2. **피어슨 상관계수**: 공분산 ÷ (X 표준편차 × Y 표준편차) → **-1 ~ 1로 표준화**
3. **1에 가까우면** 양의 관계, **-1에 가까우면** 음의 관계, **0이면** 직선 관계 거의 없음
4. 상관계수가 0에 가까워도 **곡선 관계**일 수 있으니 그래프로 꼭 확인할 것
