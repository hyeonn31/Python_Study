# DataFrame 살펴보기 정리 (은행 대출 데이터로)

데이터를 불러오고 나서 제일 먼저 하는 일들을 배웠다. 몇 줄인지, 열에 뭐가 들어 있는지, 비어 있는 칸은 없는지 확인하고, 열 이름을 다듬고, 조건으로 원하는 행만 골라내기까지.
그래프처럼 눈에 보이는 결과는 없지만, 앞으로 분석할 때마다 매번 쓰게 될 기본기라서 꼼꼼하게 정리해 둔다.

## 시작 전에

### 데이터

은행의 대출 심사 내역이다. 대출 신청 한 건이 한 줄이고, 총 600줄.

| 열 (원래 이름) | 뜻 |
|---|---|
| `loan_id` | 대출 신청 번호 (LP1003 같은 형태, 겹치지 않음) |
| `married_or_not` | 결혼 여부 (Y / N) |
| `self_employed_or_not` | 자영업자 여부 (Y / N) |
| `applicant_income` | 신청자 수입 |
| `loan_amount` | 대출 금액 |
| `property_area` | 부동산 위치 (City / Suburb / Rural) |
| `loan_status` | 대출 승낙 여부 (Y / N) |

```python
import pandas as pd

loan_df = pd.read_csv('data/loan.csv')
loan_df
```

`loan_df`처럼 변수 이름만 마지막 줄에 쓰면 표가 예쁘게 출력된다. 줄이 많으면 앞 5줄, 뒤 5줄만 보여 주고 가운데는 `...`로 생략한다.
이것 때문에 나중에 헷갈린 적이 있다. 결측값을 채웠는데 결과에 안 보여서 안 된 줄 알았는데, 채워진 행이 그냥 `...` 안에 숨어 있었던 거였다.

## 1. 데이터 훑어보기

### head(), tail()

```python
loan_df.head()    # 앞 5줄
loan_df.tail()    # 뒤 5줄
```

괄호 안에 숫자를 넣으면 그만큼 보여 준다. `head(10)`이면 앞 10줄.
데이터가 어떻게 생겼는지 감 잡을 때 제일 먼저 쓴다.

```python
loan_df.shape   # (600, 7)
```

`(행 개수, 열 개수)`. 600줄에 열이 7개라는 뜻이다.
**괄호를 안 붙인다.** `shape()`라고 쓰면 에러가 난다. 함수가 아니라 DataFrame이 원래 갖고 있는 정보(속성)라서 그렇다. 아래 `dtypes`, `columns`도 마찬가지.

### dtypes

숫자여야 하는 열이 `str`로 나오면 뭔가 문제가 있다는 신호다. 숫자 안에 `"`나 `,` 같은 기호가 섞여 있는 경우가 많다. (스마트폰 실습에서 `size` 열이 `6.1"`처럼 생겨서 문자로 인식된 게 딱 이 경우였다.)

### describe()

```python
loan_df.describe()                # 숫자 열만
loan_df.describe(include='all')   # 문자 열까지 전부
```

통계량을 요약해 준다. 기본은 숫자 열만 보여 주고, `include='all'`을 붙이면 문자 열도 같이 나온다.
노트북 주석에는 "숫자 데이터의 통계량"이라고 써 놨는데, `include='all'`을 붙였으니 사실 문자 열까지 다 나온 거다.

**숫자 열**에서 나오는 것

| 항목 | 뜻 |
|---|---|
| `count` | 비어 있지 않은 값 개수 |
| `mean` | 평균 |
| `std` | 표준편차 (값들이 평균에서 얼마나 퍼져 있나) |
| `min`, `max` | 최솟값, 최댓값 |
| `25%`, `50%`, `75%` | 사분위수. **50%가 중간값(median)** |

**문자 열**에서 나오는 것

| 항목 | 뜻 |
|---|---|
| `count` | 비어 있지 않은 값 개수 |
| `unique` | 서로 다른 값이 몇 종류인지 |
| `top` | 제일 많이 나온 값 |
| `freq` | 그 값이 나온 횟수 |

숫자 열에는 `unique`, `top`이 `NaN`으로, 문자 열에는 `mean`, `std`가 `NaN`으로 나온다. 해당 사항이 없어서 비어 있는 거지 에러가 아니다.

한 열만 보고 싶으면 열을 먼저 고르고 `describe()`를 붙이면 된다.

```python
loan_df['amount'].describe()          # 숫자 열 → mean, std, 사분위수...
loan_df['self_employed'].describe()   # 문자 열 → count, unique, top, freq
```

## 2. 정렬하기: sort_values()

```python
loan_df.sort_values(by='loan_amount')                   # 오름차순 (작은 것부터)
loan_df.sort_values(by='loan_amount', ascending=False)  # 내림차순 (큰 것부터)
```

`by`에 기준이 될 열 이름을 넣는다. 기본은 오름차순이고, `ascending=False`를 주면 내림차순이 된다.

- 정렬해도 **인덱스 번호는 원래 번호를 그대로 들고 다닌다.** 그래서 결과의 왼쪽 번호가 555, 13, 91... 처럼 뒤죽박죽으로 나온다.
- **결측값(NaN)은 오름차순이든 내림차순이든 항상 맨 뒤로 간다.** 내림차순 결과 맨 끝에 금액이 작은 대출이 아니라 `NaN`이 보이는 이유다. `loan_amount`에 결측값이 11개 있어서 끝 11줄은 전부 `NaN`이다.
- `sort_values()`는 정렬된 **결과를 보여 줄 뿐 원본은 그대로**다. 계속 쓰려면 `loan_df = loan_df.sort_values(...)`처럼 다시 저장해야 한다.

## 3. 인덱스 바꾸기: set_index()

```python
loan_df = loan_df.set_index('loan_id')
```

기본 인덱스는 0, 1, 2, ... 번호인데, 이걸 `loan_id` 열로 바꿨다.
`loan_id`는 신청 건마다 겹치지 않는 값이라 행 이름으로 쓰기 딱 좋다. 이제 0번 행이 아니라 `LP1003` 행이라고 부를 수 있다.

- 인덱스로 올라간 열은 **일반 열 목록에서 빠진다.** 그래서 이후 `columns`를 보면 7개가 아니라 6개다.
- 이것도 원본을 안 바꿔서 `loan_df =`로 다시 저장해야 한다. 노트북에서 처음엔 `loan_df.set_index('loan_id')`만 실행해서 결과만 보고, 다음 셀에서 저장까지 했다.
- `set_index` 셀을 **두 번 실행하면 에러가 난다.** 첫 실행에서 `loan_id`가 이미 인덱스로 올라가서 일반 열에 없기 때문. `read_csv` 셀부터 다시 실행하면 된다.

반대로 인덱스를 다시 0, 1, 2... 번호로 돌리고 싶으면 `reset_index()`를 쓴다.

```python
loan_df.reset_index()            # loan_id가 다시 일반 열로 내려옴
loan_df.reset_index(drop=True)   # 원래 인덱스는 버리고 번호만 새로 매김
```

`drop=True`는 행을 지운 뒤 번호가 0, 2, 3...처럼 듬성듬성해졌을 때 다시 매기는 용도로 쓴다. (결측값 단원에서 1번 행이 안 보였던 게 이 경우였다. `fillna` 때문이 아니라 그 전에 행이 지워져서 번호가 비어 있었다.)

## 4. 열 이름 다루기

### columns: 열 이름 보기

```python
loan_df.columns
```

```
Index(['married_or_not', 'self_employed_or_not', 'applicant_income',
       'loan_amount', 'property_area', 'loan_status'], dtype='str')
```

열 이름만 쏙 뽑아 준다. 열 이름을 복사해서 쓸 때 편하다.

### columns에 새 목록 넣기: 전부 바꾸기

```python
loan_df.columns = ['married', 'self_employed', 'applicant_income', 'loan_amount', 'property_area', 'loan_status']
```

`_or_not`이 붙어 있어서 이름이 너무 길었다. 목록을 통째로 새로 넣으면 열 이름이 한 번에 바뀐다.

- 목록의 **개수와 순서가 기존 열과 정확히 맞아야** 한다. 개수가 다르면 에러가 나고, 순서가 틀리면 이름이 엉뚱한 열에 붙는다.
- 바꾸고 싶지 않은 열도 목록에 원래 이름 그대로 다 적어야 한다.

### rename(): 일부만 바꾸기

```python
new_columns = {'applicant_income': 'income', 'loan_amount': 'amount'}
loan_df = loan_df.rename(columns=new_columns)
```

`{'원래 이름': '새 이름'}` 모양의 딕셔너리를 넘기면 **적은 열만** 바뀐다. 나머지 열은 안 건드린다.
몇 개만 바꿀 땐 이게 훨씬 안전하다. 순서를 신경 쓸 필요도 없고.

| 방법 | 언제 |
|---|---|
| `columns = [...]` | 열 이름을 전부 갈아엎을 때 |
| `rename(columns={...})` | 몇 개만 바꿀 때 |

`rename()`도 결과만 보여 주는 거라 `loan_df =`로 저장해야 반영된다.
이렇게 해서 최종 열 이름은 `married`, `self_employed`, `income`, `amount`, `property_area`, `loan_status`가 됐다.

## 5. 데이터 타입 바꾸기: astype()

```python
loan_df['income'].astype('float')                       # 결과만 보기
loan_df['income'] = loan_df['income'].astype('float')   # 원본에 저장
```

`income`을 정수(`int64`)에서 소수(`float64`)로 바꿨다. 4583 → 4583.0.

노트북에서 직접 겪은 것: `astype('float')`만 실행하고 `dtypes`를 다시 찍어 봤더니 **여전히 `int64`**였다. 결과만 보여 줬지 원본은 안 바뀐 거다. `loan_df['income'] =`로 다시 넣어 주고 나서야 `float64`로 바뀌었다.

오늘 계속 나온 패턴인데, pandas 함수는 대부분 **원본을 안 바꾸고 새 결과를 돌려준다.**
`sort_values`, `set_index`, `rename`, `astype`, `fillna`, `dropna`, `drop`, `drop_duplicates` 다 그렇다. 계속 쓰려면 꼭 다시 저장하기.

```python
# 표 전체를 바꿀 때
loan_df = loan_df.함수(...)

# 열 하나만 바꿀 때
loan_df['열'] = loan_df['열'].함수(...)
```

자주 쓰는 타입 이름

| 쓰는 값 | 바뀌는 타입 |
|---|---|
| `'int'` | 정수 |
| `'float'` | 소수 |
| `'str'` | 문자 |

문자를 숫자로 바꿀 때는 `"` 같은 기호를 먼저 지워야 한다. `'6.1"'.astype(float)`는 에러가 나고, `str.strip('"')`로 기호를 없앤 뒤에 `astype(float)`를 해야 된다.

## 6. 문자 열 살펴보기

`self_employed`처럼 Y/N 같은 값이 들어 있는 열(범주형 데이터)은 평균 같은 걸 낼 수 없으니, 어떤 값이 몇 개 있는지를 본다.

### unique(): 어떤 값들이 있나

```python
loan_df['self_employed'].unique()
```

```
['N', 'Y', nan]
```

중복 없이 어떤 값들이 들어 있는지 보여 준다. **결측값(`nan`)도 같이 나온다.**
오타나 이상한 값이 섞여 있는지 확인할 때 좋다. 예를 들어 `'Y'`, `'y'`, `'Yes'`가 섞여 있으면 여기서 바로 보인다.

### value_counts(): 값마다 몇 개인가

```python
loan_df['self_employed'].value_counts()
```

```
N    488
Y     80
```

값별 개수를 많은 순서대로 보여 준다.
그런데 488 + 80 = 568이라 600이 안 된다. **기본적으로 결측값은 빼고 센다.**

```python
loan_df['self_employed'].value_counts(dropna=False)
```

```
N      488
Y       80
NaN     32
```

`dropna=False`를 주면 결측값도 같이 센다. 이제 합이 600이 맞다.
`dropna`는 "결측값을 버려라"라는 뜻이라, `False`로 주면 "버리지 마"가 된다.

```python
loan_df['self_employed'].value_counts(dropna=False, normalize=True)
```

```
N      0.813333
Y      0.133333
NaN    0.053333
```

`normalize=True`를 주면 개수 대신 **비율**이 나온다. 다 더하면 1.
자영업자가 아닌 사람이 약 81%, 자영업자는 약 13%, 모르는 사람이 약 5%다.

| 옵션 | 결과 |
|---|---|
| `value_counts()` | 개수, 결측값 제외 |
| `dropna=False` | 개수, 결측값 포함 |
| `normalize=True` | 비율 |

## 7. 여러 조건으로 불린 인덱싱하기

이번 단원에서 제일 중요하고, 실습에서 제일 많이 틀린 부분이다.

### 불린 인덱싱 복습

```python
condition1 = loan_df['married'] == 'Y'
```

이렇게 하면 결과가 표가 아니라 행마다 True/False가 들어 있는 시리즈가 나온다.

```
loan_id
LP1003     True
LP1005     True
LP1008    False
...
```

이걸 대괄호 안에 넣으면 **True인 행만** 남는다.

```python
loan_df[condition1]   # 결혼한 사람만
```

조건을 변수에 따로 담아 두면 긴 코드가 훨씬 읽기 쉬워진다.

### 조건 연결하기: &, |, ~

```python
condition1 = loan_df['married'] == 'Y'
condition2 = loan_df['income'] > loan_df['income'].mean()   # 평균 수입은 약 5412

loan_df[condition1 & condition2]   # 결혼했고 그리고 수입이 평균보다 큼 → 120건
loan_df[condition1 | condition2]   # 결혼했거나 또는 수입이 평균보다 큼 → 442건
```

| 기호 | 뜻 | 파이썬 기본 문법 |
|---|---|---|
| `&` | 그리고 (둘 다 True) | `and` |
| `\|` | 또는 (하나라도 True) | `or` |
| `~` | 반대로 (True ↔ False) | `not` |

pandas에서는 `and`, `or`, `not`을 쓰면 에러가 난다. 반드시 기호로 써야 한다.
`&`는 조건이 늘수록 결과가 줄고(120건), `|`는 늘어난다(442건).

### 괄호는 꼭 쳐야 한다

변수에 담지 않고 한 줄로 쓸 때는 **조건마다 괄호**를 쳐야 한다.

```python
# O
loan_df[(loan_df['married'] == 'Y') | (loan_df['income'] > loan_df['income'].mean())]

# X → TypeError
loan_df[loan_df['married'] == 'Y' & condition2]
```

파이썬은 `==`, `>`보다 `&`, `|`를 먼저 계산한다. 그래서 괄호가 없으면 `'Y' & condition2`부터 계산하려다 에러가 난다.
조건 하나하나를 괄호로 감싸는 게 습관이 되면 편하다.

### ~ 로 반대 조건 만들기

```python
# 결혼을 했거나, (수입이 평균보다 크고 부동산이 도시에 있지 않은) 사람
condition3 = loan_df['property_area'] == 'City'
loan_df[condition1 | (condition2 & ~condition3)]   # 426건
```

`~condition3`은 "City가 아닌", 즉 Suburb이거나 Rural인 행이다.
`loan_df['property_area'] != 'City'`라고 써도 결과가 같다.

노트북에 주석으로 남겨 둔 다른 버전도 있다.

```python
loan_df[(loan_df['property_area'] != 'City') & (loan_df['income'] > loan_df['income'].mean()) | (loan_df['married'] == 'Y')]
```

순서는 다르지만 이것도 426건으로 결과가 똑같다. `&`가 `|`보다 먼저 계산되기 때문이다. 곱셈이 덧셈보다 먼저인 것과 비슷하다.
그래도 헷갈리니까 **묶고 싶은 부분은 괄호로 직접 묶는 게** 안전하다. 내가 의도한 순서가 코드에 그대로 보인다.

### 조심! ~ 와 결측값

대출 실습에서 "자영업자가 아닌 사람"을 이렇게 골랐었다.

```python
~(loan_df['self_employed'] == 'Y')   # 520건
loan_df['self_employed'] == 'N'      # 488건
```

같은 뜻 같은데 개수가 다르다. 차이 32건은 `self_employed`가 **비어 있는 사람들**이다.

- `== 'Y'`에서 결측값은 False로 나온다.
- 그걸 `~`로 뒤집으면 True가 되어서, 결측값인 사람까지 "자영업자 아님"으로 들어가 버린다.

"자영업자가 아니다"를 고를 때는 `== 'N'`처럼 **원하는 값을 직접** 쓰는 게 정확하다.

### 조심! 결과를 변수에 저장할 때

대출 실습 문제는 "조건을 만족하는 데이터를 `group1`에 저장하라"였는데, 조건(True/False)을 저장해서 틀렸다.

```python
# X: group1에 True/False 시리즈가 들어감
group1 = condition1 & condition2 & condition3
loan_df[group1]

# O: group1에 걸러진 DataFrame이 들어감
group1 = loan_df[condition1 & condition2 & condition3]
group1
```

**조건**과 **조건으로 걸러낸 데이터**는 다른 거다. 문제에서 "데이터를 저장하라"고 하면 대괄호로 걸러낸 결과를 저장해야 한다.

## 실습하면서 배운 것

### 중간값은 median()

```python
loan_df['income'].median()
```

"수입이 중간값 이상인 사람" 조건을 만들 때 썼다.

```python
condition = loan_df['income'] >= loan_df['income'].median()
```

평균(`mean()`)은 수입이 엄청 큰 사람 몇 명 때문에 위로 끌려 올라갈 수 있다. 수입 최댓값이 81000이라 평균(5412)이 중간값(3806)보다 꽤 크다.
그래서 "보통 사람" 기준으로는 중간값이 더 적당할 때가 많다. `describe()`의 `50%`가 중간값이랑 같은 값이다.

### drop()으로 열 지우기 + KeyError

```python
loan_df = loan_df.drop(columns='married')
```

이 셀을 두 번 실행했더니 `KeyError`가 났다.
첫 실행에서 `married`가 이미 지워졌는데, 두 번째 실행에서 또 지우려고 해서 "그런 열 없음" 에러가 난 거다.

`loan_df = loan_df.함수()` 모양으로 원본을 덮어쓰는 셀은 **한 번만 실행**해야 한다. 다시 하고 싶으면 `read_csv` 셀부터 순서대로 다시 실행하기.
`drop(columns='married', errors='ignore')`처럼 쓰면 없는 열은 그냥 넘어가서 에러가 안 난다.

`drop`에서 `axis`로도 쓸 수 있는데 숫자가 헷갈려서 `columns=`를 쓰는 게 편하다.

```python
loan_df.drop('married', axis=1)     # axis=1 → 열
loan_df.drop(columns='married')     # 같은 뜻, 이게 더 읽기 쉬움
```

|---|---|

### 꼭 기억할 것 세 가지

1. **pandas 함수는 대부분 원본을 안 바꾼다.** 계속 쓰려면 `df = ...`로 다시 저장하기.
2. **원본을 덮어쓰는 셀은 한 번만 실행하기.** 꼬이면 `read_csv`부터 다시.
3. **여러 조건은 `&`, `|`, `~`와 괄호로.** `~`는 결측값까지 뒤집어서 포함하니 조심.
